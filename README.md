**Project Overview**

A one-page, fully responsive landing site for Usman Dental Studio, a dental clinic in Nowshera, KP, Pakistan. Built with plain HTML, CSS, and JavaScript — no frameworks, no backend, no database — so it runs anywhere as a static site.

Build track: Luxury Dental — dark background, gold accents, elegant serif headings.

**Project Objective**

To design and build a professional, production-quality dental clinic landing page that demonstrates real-world frontend skills: responsive layout, custom design identity, interactive JavaScript features, and a deployable static site — completed as Project 3 of Month 2 in the CloudExify Summer Internship 2026.

About Clinic

Usman Dental Studio is a fictional dental clinic created for this project, based in Nowshera, KP, Pakistan, and led by Dr. Usman (BDS, 15 years' experience in Cosmetic & Restorative Dentistry). The clinic is positioned as a premium, patient-focused practice offering general, cosmetic, and family dentistry — the kind of business this landing page is designed to represent and sell to real visitors.

Problem Statement

Many small and mid-sized dental clinics don't have a professional web presence — either no website at all, or one that looks like an unmodified template and fails to build trust with new patients. This makes it harder for them to be found online, showcase real results, or let patients book appointments without a phone call. This project solves that by building a clinic landing page that looks custom-designed, clearly communicates services and pricing, shows credible proof (stats, testimonials, before/after results), and lets a visitor request an appointment directly from the page.
Project Scope

In scope:

A fully responsive, single-page static website (HTML/CSS/JS + Bootstrap 5)
All content sections: hero, services, stats, about, results gallery, testimonials, pricing, FAQ, appointment modal, contact, footer
Client-side form validation for the appointment request
Deployment as a static site (e.g. Vercel)

**Features**
Sticky navbar with smooth scroll + mobile menu
Hero section with entrance animation
6 service cards (Cleaning, Whitening, Braces, Root Canal, Implants, Cosmetic)
Animated stats counter (500+ patients, 15+ years, 98% satisfaction, 12+ specialists)
About section with doctor profile (Dr. Usman) and certification badges
Draggable before/after comparison slider (3 treatments)
Testimonials carousel (auto-rotating)
3-tier pricing with "Most Popular" highlight
FAQ accordion (8 questions)
Appointment booking modal with form validation
Contact section with embedded map (Nowshera)
Footer with quick links and social icons


**Signature Features**
Animated Statistics Counter — numbers count up from 0 using IntersectionObserver, triggered only when the section scrolls into view.
Before & After Comparison Slider — custom vanilla-JS drag slider (range input + clip-path) for whitening, implant, and cosmetic results.
Appointment Modal — Bootstrap modal with hand-written validation (name, phone pattern, date, time) and a past-date block.
Testimonials Carousel — Bootstrap carousel with auto-rotation and manual controls.

Installation & Setup
Download or clone this folder.
Open index.html directly in a browser — no build step or dependencies required.
For live-reload while editing, open the folder in VS Code and run it with the Live Server extension.

**Deployment**
Push this folder to GitHub, then import the repo into Vercel with framework preset Other (no build command needed) and deploy. Copy the resulting .vercel.app link into the Live Demo section above.
